## Comment utiliser

### Dans le HTML :
```html
<i class="fas fa-soccer-ball"></i>
```

### Avec du texte :
```html
<button>
  <i class="fas fa-download"></i> Télécharger
</button>
```

### Avec Tailwind ou CSS personnalisé :
```html
<div class="text-green-600 text-2xl">
  <i class="fas fa-check-circle"></i>
</div>
```

### Animations disponibles :
```html
<i class="fas fa-spinner fa-spin"></i>      <!-- Rotation -->
<i class="fas fa-circle-notch fa-spin"></i> <!-- Spinner -->
<i class="fas fa-spinner fa-pulse"></i>     <!-- Pulse -->
```

## CDN utilisé

